# cov_context_dependence
Analysis of contextual influence on polymorphisms in covid-19 and simulation.

# Simulation
Simulating covid-19 polymorphisms based on context-dependent polymorphisms (CDP) derived from GISAID population data can be done by running simulation.py using the preset parameters. By default, the following process is executed and utilizes the [GISAID reference sequence](https://github.com/Jwcaraway77/cov_context_dependence/blob/main/EPI_ISL_402124.fasta). 1. Relative CDP rates are calculated from sequencing polymorphism calls obtained from [cov-spectrum](https://cov-spectrum.org) (*6*) which uses data from [GISAID](https://gisaid.org) (*3*) for variants located in [sim_ref_data](https://github.com/Jwcaraway77/cov_context_dependence/tree/main/sim_ref_data). 2. Three types of simulations are run *100* times each based on the *All* CDP derived variant in which *1000* polymorphisms are placed throughout the genome. The naive simulation is 4-parameter and estimates the likelyhood of a nucleotide to change. The Ts/Tv simulation increases the resolution of simulation by incorporating the resulting nucleotide creating a 12-parameter model. Additionally, the full-context simulation includes contextual information from the 5' and 3' neighboring nucleotides resulting in a 144-parameter model (see methods for removing A[X>Y]N contexts). 3. Simulations are analyzed and organized. 4. Variant CDP matrices are correlated and pooled variants *All*, *Persistent*, and *Transient* are visually compared.

# Reference Data
[sim_ref_data](https://github.com/Jwcaraway77/cov_context_dependence/tree/main/sim_ref_data) includes two datasets, population data derived from [GISAID](https://gisaid.org) (*3*) and mutation data obtained from [NCBI](https://www.ncbi.nlm.nih.gov/genbank/) following the analysis performed by *Symons et al* (*16*). Variant folders are populated with CDP matrices at increasing minimum allele frequency thresholds after step 1 listed above. The population polymorphism dataset obtained from GISAID sequencing has been split into three GISAID EPI_sets: 
- alpha, delta : [EPI_SET_251001wt](https://gisaid.org/EPI_SET_251001wt)
- omciron, kraken, pirola : [EPI_SET_251001r](https://gisaid.org/EPI_SET_251001r)
- beta, epsilon, eta, gamma, iota, kappa, lambda, mu, hongkong : [EPI_SET_251001tk](https://gisaid.org/EPI_SET_251001tk)
